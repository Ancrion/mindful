CRITICAL ISSUES BREAKDOWN
================================================================================

ISSUE 1: INCONSISTENT BUTTON STYLES
Problem: 3 different padding schemes across 6+ files
- profile.css: padding: 10px 18px
- documents.css: padding: 9px 16px
- todo.css: padding: 12px 20px
Impact: Buttons look inconsistent across pages
Fix: Standardize to single .btn-primary component

ISSUE 2: NO TYPOGRAPHY SCALE
Problem: Font sizes hardcoded throughout (10px-48px)
Examples: 48px, 38px, 36px, 32px, 28px, 26px, 22px, 20px, 18px, 16px, 15px, 14px, 13px, 12px, 11px, 10px
Impact: Cannot change typography globally, poor readability hierarchy
Fix: Create CSS variables for font sizes (--text-xs through --text-2xl)

ISSUE 3: NO SPACING SCALE
Problem: Padding/margins scattered (2px to 60px without pattern)
Impact: Components misaligned, inconsistent spacing
Fix: Create spacing scale variables (--space-1 through --space-6)

ISSUE 4: HARDCODED SECONDARY COLORS
Problem: Colors like #10B981, #f59e0b, #EF4444 hardcoded
Impact: Cannot change color scheme globally, maintenance nightmare
Fix: Move all colors to CSS variables in :root

ISSUE 5: NAMING CONVENTION CHAOS
Problem: Prefixes scattered (widget-*, task-*, cal-*, no prefix)
Impact: Styles not reusable, difficult to maintain
Fix: Implement BEM or consistent naming convention

ISSUE 6: MISSING FOCUS STATES
Problem: No :focus-visible styles on interactive elements
Impact: Keyboard navigation broken, accessibility issue
Fix: Add :focus-visible { outline: 2px solid var(--accent); } throughout

ISSUE 7: SCATTERED DARK MODE
Problem: body.dark overrides scattered across all 10 files
Impact: Maintenance nightmare, hard to track dark mode bugs
Fix: Consolidate all dark mode styles to one location or separate file
